# Войны Стихий

Первая рабочая версия помощника НРИ на Python 3.12, Django 5.2 и PostgreSQL.

## Запуск

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.lock
# Создайте PostgreSQL БД, задайте DB_NAME/DB_USER/DB_HOST и SECRET_KEY.
.venv/bin/python manage.py migrate
# Только при первом запуске: передайте ADMIN_INITIAL_PASSWORD через окружение.
.venv/bin/python manage.py bootstrap
.venv/bin/python manage.py collectstatic --noinput
.venv/bin/gunicorn config.wsgi:application
```

Мастер — единственный аккаунт `admin`. Первоначальный пароль поступает из окружения и не сбрасывается при повторном запуске. Регистрация создаёт только игроков. `.env` не загружается автоматически: передайте значения окружением или через EnvironmentFile в systemd.

Для локальной разработки можно использовать `DEBUG=1 TEST_SQLITE=1` и `manage.py runserver`. SQLite используется только как необязательный режим локальной разработки/быстрых тестов; на ВМ приложение работает на PostgreSQL.

## Что реализовано

- Регистрация, вход, разграничение прав, приватные заметки владельца.
- Листы с фотографией, свободным редактированием характеристик, класса, школ, уровня и списка умений. Расчёт модификаторов, классовых ХП, КД, скорости и навыков.
- Кампании, отряды, самостоятельное вступление персонажей, игровые сессии мастера.
- Справочники и поиск, добавление/редактирование мастером, архивирование записей. Импорт 1 012 записей из книги: не все имеют автоматическую механику.
- Личный/общий инвентарь, экипировка и передача предметов.
- Очередь персонажей без монстров, отдельные действия, запас у каждого умения, ввод физических бросков до применения.
- Автоматические настраиваемые бонусы, Благословение, временные ХП, получатели ауры, сроки по ходам цели.
- Ручное изменение ХП мастером, отдельный экран показа. Фиксированные числовые лечение/временные ХП автоматические; результаты от Мод/кубиков — ручные.
- Восстановление ХП и использований в конце боя, сброс временных ХП и боевых эффектов.
- Отмена/повтор собственного последнего события с защитой от отката чужих зависимых изменений.
- Обновления состояния опросом раз в 2 секунды. Общие заметки объединяют независимые изменения; пересечения одного фрагмента требуют ручного разрешения.

## Границы первой версии

Полная автоматизация книги не завершена. Импортированные описания отмечены как ручные: их применение учитывает действия и запас, но сложные реакции, случайные ветки, призывы, зоны, усиления и большинство пассивных способностей пока обрабатываются участниками по описанию. «Учебная аура защиты» — явно помеченный пример настройки, не правило книги. Мастер задаёт сложные эффекты через расширенные параметры; полноценный визуальный конструктор ещё не сделан.

Критический урон реализован по согласованным примерам, плоские прибавки не умножаются. Наложение посреди хода цели считает ближайший конец её хода первым; это временное техническое правило до уточнения. Небоевые умения только отображаются вне боя. Смена экипировки в активном бою пока запрещена вместо автоматизации стоимости смены. В боевой сцене хранятся только эффекты текущего боя; долгосрочные эффекты и их жизненный цикл ещё не реализованы.

Совместные заметки пока не являются полным CRDT/Google Docs: независимые текстовые правки сливаются, конфликт одного фрагмента не затирает текст, но требует ручного разрешения. Приватные заметки недоступны другим аккаунтам, включая мастера в интерфейсе; администратор самой БД технически имеет доступ к хранимым данным.

В первой версии базовые ХП после изменения Телосложения пересчитываются на все уровни, текущие ХП не лечатся от редактирования листа. Пока не реализованы: отдельная модель мировоззрения с графом приоритетов, рецепты крафта, подбор подрас с автоматическими бонусами, произвольные владения со сложными условиями, версии правил в старых боях, самостоятельное удаление персонажа (мастер может управлять им через Django admin).

## Проверка

```sh
TEST_SQLITE=1 .venv/bin/python manage.py test game
.venv/bin/python manage.py check
# Для полноценного PostgreSQL теста используйте отдельную тестовую БД/роль.
```

Тесты покрывают права, приватность, ХП, эффекты на три хода, конец боя, критические примеры, повтор запроса, отмену, слияние заметок и передачу предметов. Подробные требования: [docs/product-spec.md](docs/product-spec.md), дизайн: [docs/ui-ux.md](docs/ui-ux.md).
