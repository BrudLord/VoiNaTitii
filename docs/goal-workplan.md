# Рабочая карта полной реализации

Цель: все требования пользователя и все игровые правила книги, единый компактный фэнтезийный интерфейс для ноутбука и телефона. Наличие импортированного текста не является реализацией правила. Завершение доказывается сценарием применения и проверкой изменения состояния.

## Этапы и доказательства

- [ ] Матрица всех глав и 863 блоков: источники, триггеры, выборы, расчёт, эффекты, срок, расход, отмена; каждой механике соответствует исполняемый сценарий.
- [ ] Применение: цели, физические броски, распределение лечения, условные и разовые бонусы, усиления, реакции и ауры, итоговый бонус попадания и формула урона.
- [ ] Персонаж: раса/подраса, класс/школы, навыки, предыстория, ремесло, специализации; свободное редактирование и смена небоевых умений.
- [ ] Интерактивный круг мировоззрения и связанные доступные приоритеты/умения.
- [ ] Предметы: типовые формы для денег, оружия, доспехов, щитов, расходников и прочего; зачарования, бонусы, заряд/расход, частичная передача, общий/личный запас.
- [ ] Книга знаний: изученные зачарования, рецепты, контакты, личные сведения и связи с вещами.
- [ ] Кампания: отряд, сессии, отдельный квестбук и структурированные совместные записи с защитой от конфликтов.
- [ ] UI: кастомные доступные списки, единый стиль, основной лист и управление боем в одном экране ноутбука; отдельные прокручиваемые панели больших коллекций; мобильные сценарии.
- [ ] Проверка каждого сценария, PostgreSQL, визуальная проверка ноутбука/телефона, развёртывание и проверка рабочей версии.

## Текущая работа

Добавлены отдельный квестбук и структурированные записи кампании (этапы, статусы, заказчик, награда, метки, архив/восстановление). Оптимистическая блокировка защищает совместное редактирование. Общая заметка сохранена внутри раздела записей. Отряд, сессии, квесты, записи, общий запас разделены вкладками.

Кастомные списки поддерживают поиск, клавиатуру и динамические зависимые варианты. Исправлен тип вспомогательных кнопок в формах: они больше не отправляют форму. 24 локальных серверных теста прошли; браузер: создание/редактирование квеста с этапами, поиск статуса и Enter, фильтрация завершённых, размеры 1280×720 и 390×844. После корректировки высота страницы кампании равна высоте окна (720 px).

Следующая работа: типовой инвентарь и зачарования, книга знаний персонажа; затем вычислитель применения и полная матрица правил. Дополнительно проверить мобильную форму с экранной клавиатурой и независимое изменение двух записей через две браузерные сессии. Галочки ставятся только по завершённым проверкам всей области.


## 12 сентября: мировоззрение, типы вещей, «Глыба»

Реализован интерактивный круг по изображению главы 8. Сплошные связи: Независимость = Личное + Свобода; Творчество = Свобода + Хаос; Равенство = Хаос + Общее; Коллектив = Общее + Необходимость; Закон = Необходимость + Порядок; Статус = Порядок + Личное. Пунктирные одиночные связи включаются только при отсутствии доступной сплошной связи из соответствующей ценности. Проверяется сервером. Выбор приоритета показывает активные/пассивные небоевые умения; переключение умения обновляет изученный набор.

Типовые формы предметов: золото (только количество), оружие (кубики, Крит, характеристика, свойства), доспех/щит (защита), расходник/прочее (описание). Бонусы к попаданию, урону, КД, скорости, максимуму ХП — отдельный блок; бонусы оружия к попаданию/урону действуют только при атаке выбранным оружием. Метаданные шаблона сохраняются. Нулевое количество допустимо, золото/расходник нельзя надеть.

«Глыба»: один бонус Землёй за ход сцены, промах не расходует, крит не умножает плоскую прибавку, отмена/повтор восстанавливают расход; для безусловных скомпилированных эффектов Оглушения показывается дополнительный урон по силе. Это не доказательство покрытия всех условных накладываний Оглушения — их нужно проверить при работе с интерпретатором умений.

Обнаружена и исправлена коллизия ключа снятия эффекта и идентификатора запроса (мастерское снятие + отмена).

Браузер: сохранение мировоззрения и изученного умения, добавление золота; проверка 390×844 и ноутбука. Геометрическая проверка всех пар кнопок круга: пересечений нет, ширина мобильной страницы 390 px. Проверки Python включают 32 комбинации ценностей, конкретные сплошные/пунктирные связи, запрет недоступных приоритетов, типы вещей, оружейные бонусы, ход/промах/крит/отмену Глыбы.

Следующий шаг: зачарования предметов, знания/контакты/рецепты персонажа, частичная передача и расход предметов, распределённые эффекты умений и полная матрица правил. Сверять с книгой и листом Таисии, не объявлять поддержку только на основании наличия текста.
